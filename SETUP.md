# Запуск по этапам

На каждом этапе указано, куда зайти, что нажать и что должно появиться. Ключи и пароли вводятся только в официальные окна сервисов и в GitHub Secrets. В чат их не отправляйте.

Секреты добавляются так: репозиторий на GitHub → **Settings** → **Secrets and variables** → **Actions** → **New repository secret** → поле Name (точное имя ниже) и поле Secret (значение) → **Add secret**.

---

## Этап 1. GitHub — «сервер» и расписание (около 5 минут)

1. Откройте https://github.com. Если аккаунта нет — **Sign up**, затем подтвердите почту.
2. Справа вверху нажмите **+** → **New repository**.
   - Repository name: `interes-world-autopost`
   - Выберите **Private**. Остальное не трогайте.
   - Нажмите **Create repository**.
   - Результат: пустой репозиторий со страницей «Quick setup».
3. Подключите GitHub к Claude: claude.ai → **Settings** → **Connectors** → **GitHub** → **Connect**. Откроется официальное окно GitHub — разрешите доступ к репозиторию `interes-world-autopost`.
4. Напишите Claude в чат имя репозитория в виде `ваш-логин/interes-world-autopost`.
   - Результат: Claude загружает проект. На вкладке **Actions** появляются кнопки 0–6, у «0 · Проверка кода» стоит зелёная галочка.

## Этап 2. WordPress — пароль приложения (около 3 минут)

1. Откройте https://interes-world.com/wp-admin → **Пользователи** → **Профиль**.
2. Внизу найдите **Пароли приложений**. Имя: `autopost` → **Добавить новый пароль приложения**.
3. Скопируйте показанный пароль. Он показывается один раз.
4. Добавьте в GitHub два секрета:
   - `WP_USER` — ваше имя пользователя WordPress (вверху профиля, поле «Имя пользователя»);
   - `WP_APP_PASSWORD` — скопированный пароль.

## Этап 3. Claude — токен подписки Max (около 5 минут, один раз в год)

1. На компьютере откройте терминал:
   - Mac: Программы → Утилиты → Терминал;
   - Windows: Пуск → PowerShell.
2. Установите Claude Code:
   - Mac: `curl -fsSL https://claude.ai/install.sh | bash`
   - Windows: `irm https://claude.ai/install.ps1 | iex`
3. Откройте новое окно терминала и выполните `claude setup-token`. Откроется официальное окно входа Claude — подтвердите доступ.
4. В терминале появится длинный токен. Добавьте его в GitHub как секрет `CLAUDE_CODE_OAUTH_TOKEN`.

Если терминал использовать не хотите, можно взять ключ API: https://platform.claude.com → API keys. Добавьте его как секрет `ANTHROPIC_API_KEY`. Тексты тогда оплачиваются отдельно — около $15–20 в месяц на Sonnet 5.5 (оценка).

## Этап 4. Facebook — своё приложение Meta (около 10 минут)

1. Откройте https://developers.facebook.com → **My Apps** → **Create App**.
   - Название: `Interes Autopost`.
   - Сценарий использования (use case): **Manage everything on your Page**.
   - Если спросят бизнес-портфолио — выберите тот, где находятся ваши страницы.
2. В приложении откройте **Dashboard** → **Customize the Manage everything on your Page use case**. Нажмите **Add** у разрешений `pages_manage_posts`, `pages_read_engagement`, `pages_manage_engagement`. `pages_show_list` и `business_management` уже добавлены.
3. Откройте **App settings** → **Basic**. Скопируйте **App ID** в секрет `FB_APP_ID`, а **App secret** (кнопка Show) — в секрет `FB_APP_SECRET`.
4. Откройте https://developers.facebook.com/tools/explorer.
   - Справа выберите Meta App: `Interes Autopost`.
   - User or Page: **User Token**.
   - В Permissions добавьте `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `pages_manage_engagement` и `business_management`.
   - Нажмите **Generate Access Token**. В официальном окне Facebook отметьте **все 34 страницы** и подтвердите.
5. Скопируйте токен в секрет `FB_USER_TOKEN`. Он действует около часа, поэтому сразу переходите к пункту 6.
6. GitHub → **Actions** → **2 · Подключить Facebook** → **Run workflow**.
   - Результат: в отчёте «Получены токены страниц: **34 из 34**», срок — «бессрочно».
   - После этого секрет `FB_USER_TOKEN` можно удалить.

## Этап 5. Проверка подключений (ничего не публикует)

GitHub → **Actions** → **1 · Проверка подключений** → **Run workflow**.
- Результат: все пункты с ✅ — Facebook (34 страницы), WordPress, Claude, источник историй.

## Этап 6. Закрытый тест (ничего не публикует)

**Actions** → **3 · Закрытый тест** → **Run workflow**. В поле `source` вставьте ссылку на любую вашу историю с фото (полную, не `/share/`). Если поле пустое, будет взята новая история, опубликованная на одной из страниц после этапа 4.

Что происходит:
- Claude пишет тексты на 4 языка;
- на сайте создаётся черновик, в Facebook — отложенный пост на неделю вперёд;
- после проверки оба удаляются.

Claude покажет вам тексты и выбранную тестовую страницу.

## Этап 7. Публичный тест (1 пост на 1 странице)

После вашего «да»: **Actions** → **4 · Публичный тест** → поле confirm: `PUBLISH` → **Run workflow**.
- Результат: на странице есть пост с фото, первым комментарием стоит ссылка на статью, статья открывается.

## Этап 8. Включение расписания

Подтвердите часы публикаций — Claude пропишет их. Затем **Actions** → **6 · Включить или выключить расписание** → `on`.

Дальше всё работает само: 5 раз в день, 34 страницы, без подтверждения каждого поста. Чтобы остановить — та же кнопка, значение `off`.
